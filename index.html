ABOUT ME

And I'm addicted to dashboards

I'm a Senior Executive — Data Analyst & Power BI Developer at Kitchens@ (Loyal Hospitality Pvt. Ltd.), a cloud kitchen network running 700 kitchens across 45 locations in 6 cities. I built the company's entire BI function on my own, from the first data connection to the semantic model, and now own 30+ production dashboards used every day by the CEO, COO, Finance, BD, and Operations teams. I went from fresher to Senior Executive in about 10 months.

  • Standardizing Swiggy and Zomato aggregator metrics through shared Power BI Dataflows (Gen1) instead of duplicating Power Query logic per report
  • Hub-level P&L matrices — a 40-row disconnected metrics table driven by a single SWITCH measure, with sign-based conditional formatting
  • Unit-level cost matrices covering NMV, food cost, food cost %, packaging cost, and COGS
  • Keeping the on-premises gateway and auto-refresh schedule reliable as dashboard count and page depth grow

Power BI, DAX, and Power Query (M) are home turf, running on an on-premises gateway with scheduled auto-refresh. Behind them: PostgreSQL, MySQL, and Excel for source data; Python for automation and the Meta Graph API; and Power Automate and n8n for workflow automation. Row-level security runs on ISINROLE().

Kitchens@

Modeling & DAX depth

Semantic model & measure design

  • Core model built around a Sales Summary Report Itemwise fact table with Brand, Hub, Date, and Item dimensions, plus multiple inactive relationships activated per-measure with USERELATIONSHIP.
  • Built a TREATAS-based virtual relationship bridging a daily fact table and a counters table on date and CC9 columns to fix date slicer/filter context bugs.
  • Hub-level P&L matrix driven by a 40-row disconnected metrics table and a single SWITCH-based measure, with gold/green/red conditional formatting and blank-suppression logic.
  • COGS measures rewritten with LASTNONBLANK and SUMX for correct non-additive total-row behavior.
  • WoW/MoM complaint delta measures using SELECTEDVALUE + ALL patterns with HASONEVALUE guards.

Kitchens@

Pipelines & data engineering

ETL, Power Query, calculated tables

  • ETL from PostgreSQL, MySQL, and Excel into the model via scheduled Import-mode loads.
  • Multi-hub utility cost allocation system splitting merged meter readings between two brands using JSON-driven, NMV-weighted proportional logic across gas, water, and electricity — plus a pure-DAX alternative built with explicit CALCULATE/REMOVEFILTERS.
  • Calculated tables including a unioned DimDate across four fact tables, a UNION/DISTINCT Dim Platform, and LOOKUPVALUE-based Dim Hub / Dim Brand tables.
  • Designed a folder-based Swiggy/Zomato snapshot ingestion architecture with deduplication to handle data-settling lag.
